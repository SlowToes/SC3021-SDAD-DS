### Data source information

The project requires a minimum of 3 distinct data sources.

 These sources should be meaningfully different. For example, multiple files with the same structure that are simply split by time (e.g., yearly data from the same agency stored in separate CSV files) would generally be considered one data source.

If datasets come from the same provider but differ in structure or content, they may be treated as separate sources; however, it is recommended that no more than two of the required sources come from the same provider.
